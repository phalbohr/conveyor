# Triage

Order the open tasks on the board.

- Find dependencies between tasks and set "blocked by" links.
- Set a priority for each new task: 1 is the most urgent, 4 the least.
- Keep the priorities of the other tasks. Suggest a new priority for one of them only when a new task changes its urgency; the team decides.
- Put tasks that unblock other tasks first.
- Do not change the content of tasks.
